智能助手连接

连接智能助手（如各类 AI 聊天机器人）后，助手可以控制屏幕上的角色——做表情、做动作、说话，就像真正的桌面伙伴一样。
AstrBot 地址
AstrBot API Key
屏幕会主动连接 AstrBot 拉取消息（表情/动作/对话气泡），无需开放板子端口。API Key 在 AstrBot WebUI「设置 → API Key」创建，勾选 plugin / chat / file三个权限
显示会话
选择后屏幕只显示该会话的消息（私聊/群聊分开显示，互不混杂）。先保存地址和 API Key 再点 刷新
屏幕连接状态：检测中…
助手可以发送三类指令：表情（如开心、难过）、动作（如挥手、点头）、说话（显示文字气泡）
详细对接方法请参考说明书中的《智能助手对接指南》
